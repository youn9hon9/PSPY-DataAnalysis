# 서울시 CCTV 공공데이터 폴더 안내

이 폴더에는 CCTV 자체 데이터뿐 아니라 입지분석에 함께 사용할 수 있는 유동인구와 안전시설 자료가 들어 있습니다. 서로 목적과 분석 단위가 다른 파일을 한꺼번에 합치지 않도록, 자료의 역할에 따라 폴더를 나누었습니다.

## 폴더 구조

```text
서울시 CCTV 공공데이터/
├─ 01_자치구_CCTV_설치현황/
│  ├─ 01_목적별/
│  ├─ 02_범죄예방_수사용/
│  ├─ 03_연도별/
│  ├─ 04_지능형_설치현황/
│  └─ 05_지능형_수량/
├─ 02_교통_단속_CCTV/
│  ├─ 01_도시고속도로/
│  ├─ 02_불법주정차/
│  └─ 03_전용차로/
├─ 03_S-DoT_유동인구/
│  ├─ 01_설치위치/
│  └─ 02_측정데이터/2026/
├─ 04_연계_안전시설/
│  ├─ 01_스마트폴/
│  └─ 02_안심귀갓길_데이터사전/
└─ 99_메타데이터_설명서/
```

## 어떤 자료를 사용하면 됩니까?

| 분석 목적 | 먼저 살펴볼 폴더 | 한 행 또는 한 파일의 의미 |
|---|---|---|
| 자치구별 CCTV 규모와 변화 비교 | `01_자치구_CCTV_설치현황/` | 자치구별 목적·설치연도·CCTV 유형 집계의 시점별 스냅샷 |
| 좌표가 있는 CCTV로 거리·커버리지 계산 | `02_교통_단속_CCTV/` | 도시고속도로 교통 CCTV 또는 불법주정차·전용차로 단속 CCTV 한 지점 |
| 수요 지점 또는 수요 가중치 만들기 | `03_S-DoT_유동인구/` | S-DoT 센서 위치와 센서별 시점별 방문자 수 |
| 다른 안전시설과 함께 비교하기 | `04_연계_안전시설/` | 스마트폴 설치 지점과 안심귀갓길 안전시설 데이터 사전 |
| API 필드와 원본 출처 확인하기 | `99_메타데이터_설명서/` | 서울 열린데이터광장 API 명세 |

`02_교통_단속_CCTV/`의 좌표는 교통 관리와 단속 목적의 시설입니다. 이를 범죄예방 CCTV와 같은 시설로 해석하지 않으며, 수업에서 사용한다면 **거리 계산과 입지분석 절차를 연습하는 예제**라는 범위를 함께 밝힙니다.

## 파일 점검 결과

- 정리 전 원본 29개를 모두 보존했습니다. 전체 크기는 33,199,223바이트이며, SHA-256이 같은 완전 중복 파일은 없습니다.
- CSV 5개는 CP949 계열 인코딩입니다. pandas에서는 `encoding="cp949"`를 명시하는 편이 안전합니다.
- S-DoT 공식 안내에 따르면 방문자 수는 Wi-Fi 단말 신호 집계 또는 CCTV 피플카운팅 방식의 관측값입니다. 정확한 보행자 총인구가 아니라 유동량을 나타내는 대리변수로 사용합니다.
- 불법주정차 CSV는 4,607행이며 모두 `불법주정차구역`입니다.
- 전용차로 CSV는 60행이며 `버스전용차로` 46행과 `자전거전용차로` 14행으로 구성됩니다. 기존 파일명의 `(1)`은 중복을 뜻하지 않아 자료의 내용이 드러나는 이름으로 바꾸었습니다.
- `서울도시고속도로 교통CCTV 설치위치 정보_20260211.xlsx`는 시트 범위 메타데이터가 `A1:A1`로 잘못 저장되어 있습니다. 실제로는 헤더를 제외한 1,326개 레코드가 있으므로 openpyxl로 읽을 때 `worksheet.reset_dimensions()`가 필요할 수 있습니다.
- `서울시 자치구 (목적별) CCTV 설치현황('26.6.30 기준).xlsx`의 내부 제목에는 존재하지 않는 날짜인 `2026년 6월 31일`이 적혀 있습니다. 원본은 수정하지 않았으며, 분석 기준일은 파일명과 배포기관 설명을 함께 확인합니다.
- `안심귀갓길_안전시설물(코드유형).xlsx`는 위치 관측값이 아니라 데이터 구조와 코드를 설명하는 자료입니다.
- 기존 `.xls` 파일은 실제 Excel 통합문서가 아니라 HTML 형식의 API 명세였습니다. 내용에 맞추어 `99_메타데이터_설명서/서울시 불법주정차·전용차로 단속 CCTV API 명세.html`로 이름과 확장자를 정리했습니다.
