# PSPY 어깨너머 - 데이터 분석

## 자기주도 학습 방식

이 과정에는 매주 진행되는 강의가 없습니다. 참여자는 자료를 받은 뒤 자신의 속도로 `notion.md`를 읽고, `example.ipynb`를 실행하고, `assignment_baseline.ipynb`에서 작은 시도를 해 봅니다. 막힌 내용은 먼저 문제를 작게 나누어 확인하고, 혼자 해결하기 어려운 부분만 DM으로 문의합니다.

- 예제의 모든 코드를 이해하거나 과제를 끝까지 성공시키는 것이 목표는 아닙니다.
- 매주 **질문 하나, 실행 또는 분석 시도 하나, 관찰한 결과나 오류 하나**를 남깁니다.
- 막혔다면 오류 메시지, 시도한 방법, 문제를 나눈 과정과 다음 시도를 기록합니다. 이 기록도 완성된 분석과 같은 학습 결과입니다.
- 매주 한 명씩 성공한 결과뿐 아니라 예상과 달랐던 결과, 해결하지 못한 문제, 새롭게 알게 된 점을 짧은 PPT로 공유합니다.
- 발표는 평가나 심사가 아니라 서로 다른 시행착오에서 배우는 시간입니다.

### 낮춰야 할 어려움과 남겨 둘 어려움

과제의 진입 난도는 낮게 유지하되, 스스로 판단하고 시행착오를 겪을 여지는 남겨 둡니다.

| 자료에서 줄여야 할 마찰 | 학습을 위해 남겨 둘 시행착오 |
|---|---|
| 설치 명령 누락, 깨진 경로, 없는 데이터 링크 | 어떤 그래프나 변수를 선택할지 판단하기 |
| 본문과 노트북의 서로 다른 숫자·원칙 | 예상과 다른 출력의 이유를 가설로 세우기 |
| 시작하기 어려운 빈 노트북, 불필요한 대용량 로딩 | 결측치·이상치 처리 방법을 비교하기 |
| 실행에 필요한 패키지·파일명을 알 수 없는 상태 | 모델이나 지표를 바꾸고 결과를 해석하기 |

코드가 실행되지 않았거나 원하는 결과가 나오지 않았더라도, 시도와 브레이크다운을 다른 사람이 따라갈 수 있게 설명했다면 그 주의 학습을 완료한 것으로 봅니다. 구체적인 기록법과 DM 문의 형식은 [OT의 자기주도 학습 안내](00_OT/notion.md)에서 확인합니다.

CCTV 관련 파일은 로컬 자료 안내에서 용도와 경로를 확인할 수 있습니다. 심야약국 데이터는 출처 링크가 확정되면 주차 문서의 `TODO`를 갱신합니다.

## 폴더 구조

처음 참여할 때는 [OT의 학습 폴더 안내](00_OT/notion.md)를 먼저 읽습니다. 프로젝트 루트에서 아래 세 명령을 차례로 실행하면 공통 패키지 설치, 폴더 준비, 환경 확인을 진행할 수 있습니다. `python` 명령을 찾지 못하는 Windows 환경에서는 `python` 대신 `py`를 사용합니다.

```text
python -m pip install -r requirements.txt
python 00_OT/setup_folders.py
python 00_OT/check_environment.py
```

환경 확인 도구는 파일이나 인증키를 변경하지 않습니다. 설치되지 않은 패키지와 없는 공통 폴더만 알려 주며, 실제 데이터 파일은 각 주차의 준비 안내에서 따로 확인합니다. 오류가 발생했을 때의 공통 확인 순서는 [OT의 복구 사다리](00_OT/notion.md#복구-사다리)에서 찾을 수 있습니다.

```text
PSPY-DataAnalysis/
├─ 00_OT/
│  ├─ check_environment.py      # 파이썬·패키지·공통 폴더 읽기 전용 점검
│  └─ setup_folders.py          # 비어 있는 공통 폴더 생성
├─ 01주차/ ... 08주차/
│  ├─ notion.md
│  ├─ example.ipynb
│  ├─ assignment_baseline.ipynb
│  └─ assets/
├─ dataset/
│  ├─ open/                   # 공개·접근 가능한 데이터
│  │  ├─ raw/                 # 내려받은 파일과 API 원본
│  │  ├─ extracted/           # 노트북이 읽는 압축 해제 자료
│  │  └─ processed/           # 정제·병합해 새로 만든 산출물
│  └─ close/                  # 비공개·접근 제한 데이터
│     ├─ raw/
│     ├─ extracted/
│     └─ processed/
├─ .env.example
├─ requirements.txt            # 공통 필수 패키지
└─ README.md
```

각 주차의 `notion.md`는 개념과 해석 기준, `example.ipynb`는 따라 실행하는 예제, `assignment_baseline.ipynb`는 과제 시작점입니다. `assets/`에는 교재에서 바로 보여 주는 그림이 들어갑니다. 1주차에는 승인된 키로 KRX 원본을 직접 수집하는 `krx_api.py`가 추가로 들어갑니다. 인증키는 루트 `.env`의 `KRX_API_KEY`에서 읽고, 원본 JSON과 CSV는 Git에서 제외된 로컬 `dataset/`에 저장합니다. 공개 데이터는 `dataset/open/`, 비공개 또는 접근 제한 데이터는 `dataset/close/`에 구분하며 두 영역 모두 원격 저장소에는 올리지 않습니다.

베이스라인 노트북은 정답지가 아니라 **첫 시도를 시작하는 발판**입니다. 주차에 따라 데이터 로딩이나 기계적인 전처리가 일부 제공되며, 남은 부분을 모두 채우지 않아도 됩니다. 질문 하나를 정해 코드를 한 번 바꾸어 보고, 결과 또는 오류와 다음 시도를 기록하는 것이 기본 범위입니다.

## 주차별 상세 계획

모든 주차의 과제는 같은 작은 완료선을 사용합니다. 아래 네 가지를 노트북에 남겼다면 결과가 예상과 다르거나 코드가 끝까지 실행되지 않아도 이번 주 기본 기록을 마친 것입니다.

1. 궁금한 점이나 확인하고 싶은 질문 1개
2. 코드 실행 또는 실행 시도 1개
3. 확인한 결과나 오류 메시지 1개
4. 다음에 해 볼 행동 1개

각 과제의 `✅ 기본 시도`만 먼저 진행합니다. 막힌 원인을 조금 더 나누어 보고 싶다면 `🧩 문제 분해`, 여유가 있을 때 범위를 넓히고 싶다면 `🌱 선택 탐색`으로 이어갑니다. 선택 항목을 하지 않아도 기본 기록은 완료됩니다.

### OT
자기주도 학습 순서, 시행착오 기록법, DM 문의 방법과 커리큘럼을 확인합니다. 과제는 없습니다.

### 1주차 — EDA/시각화 + API 실습
- 교재: 따릉이 데이터로 결측치/이상치 확인, 기술통계, 시각화. KRX 시리즈 지수와 코스닥 종목 API를 직접 호출해 원본 JSON, 스키마 검증, 날짜별 캐시, CSV 변환까지 실습.
- 과제 베이스라인: `2024-08-23` 코스닥 종목 단면 수집을 시도하고, 준비된 상태 확인 셀에서 인증키·캐시 파일 여부를 먼저 확인합니다. 이용 조건과 보안을 고려해 실제 KRX 데이터는 저장소에 포함하지 않습니다.
- 기본 완료: API가 준비되었다면 표 한 번 또는 그래프 하나를 확인합니다. 승인이나 인증키 때문에 막혔다면 확인한 상태, 오류와 다음 행동을 기록하는 것으로 마칩니다.

### 2주차 — Linear Regression
- 교재: 따릉이 대여량 예측, 변수 선택, 단순/다중선형회귀, 잔차 분석.
- 과제 베이스라인: 감귤 데이터의 식별자 1개(`ID`), 입력 4개, 목표값 1개(총 6개 열) 로딩 코드를 제공합니다.
- 기본 완료: 데이터 상태를 확인하고 제공된 첫 회귀 시도를 실행한 뒤, RMSE나 오류 중 하나를 관찰하여 기록합니다.

### 3주차 — Decision Tree
- 교재: 따릉이로 Tree 학습, 트리 시각화, 선형모델과 비교.
- 과제 베이스라인: 전력사용량 train.csv + building_info.csv 조인 코드, 결측치 처리 예시까지 제공.
- 기본 완료: 파일·조인 상태를 확인하고 제공된 작은 트리 시도를 실행합니다. 실행 결과나 막힌 단계와 다음 행동을 기록합니다.

### 4주차 — Random Forest + 모델 비교
- 교재: 따릉이로 RF 학습, Tree/RF/LinearReg 3개 모델 성능 비교표 작성.
- 과제 베이스라인: 물류유통량의 원본 범주형 열과 train에만 fit하는 one-hot Pipeline 골격을 제공합니다.
- 기본 완료: 제공된 모델 하나를 실행하고 기준 결과와 비교하여 달라진 점 하나를 기록합니다. 세 모델을 모두 완성하는 일은 선택입니다.

### 5주차 — Classification
- 교재: Loan Prediction(Kaggle)으로 분류 파이프라인, accuracy/precision/recall/F1 개념과 계산.
- 과제 베이스라인: 항공편지연 2만 행 샘플과 분할 뒤 train에만 fit하는 결측·one-hot Pipeline 골격을 제공합니다.
- 기본 완료: 지연 여부의 개수를 확인하고 제공된 분류 시도 또는 파일 확인을 실행한 뒤, 지표나 오류 하나를 기록합니다.

### 6주차 — Clustering
- 교재: Customer Personality Analysis(Kaggle)로 K-means, 적정 K 찾기(elbow/silhouette), 클러스터 특성 해석.
- 과제 베이스라인: 이커머스 5개 테이블 join + RFM(Recency/Frequency/Monetary) 계산 완료된 고객단위 테이블 제공.
- 기본 완료: 데이터 상태를 확인하고 제공된 군집화 시도를 한 번 실행한 뒤, 군집 하나의 눈에 띄는 특징 또는 오류를 기록합니다.

### 7주차 — 사각지대/접근성 분석
- 교재: 전용차로 단속 CCTV 56개 고유 위치와 관측 완전성 기준을 통과한 S-DoT 수요 62곳으로 위경도 거리계산(하버사인), 현재 커버리지, 그리디 방식의 계산 후보 추천, 민감도 분석, 위경도 산점도를 실행합니다. `folium`이 있으면 대화형 지도를 선택적으로 저장합니다. 단속용·방범용 CCTV는 설치 목적이 다르며, 결과는 실제 설치안이 아닌 공간분석 절차 실습으로 해석합니다.
